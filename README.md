# quarantrois.

Site vitrine de Quarantrois SARL. Site statique (HTML, CSS, JavaScript), sans étape de compilation.

- `index.html` : la page complète, bilingue français et anglais.
- `assets/hero/` : les 97 images de la séquence d'ouverture.
- `assets/sectors/` : les photos des secteurs.
- `vercel.json` : mise en cache longue durée des images.

Contenus modifiables en tête du script de `index.html` : réalisations (`WORK`), expertises (`EXPERTISE`), secteurs (`SECTORS`), liens des réseaux sociaux (`SOCIAL`).
